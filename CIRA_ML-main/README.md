## 🚀 Installation & Setup

### System Requirements

- **Python**: 3.8+ (Python 3.9+ recommended for optimal ML performance)
- **RAM**: 8GB minimum (16GB recommended for large datasets)
- **Storage**: 2GB available space for datasets and models
- **Browser**: Modern web browser with JavaScript enabled
- **Network**: Internet connection for initial setup and ML model downloads

### Quick Installation

#### 1. Repository Setup

**All Platforms:**
```bash
git clone https://github.com/your-org/CIRA_ML-main.git
cd CIRA_ML-main
```

#### 2. Virtual Environment Setup

**Windows Command Prompt:**
```cmd
# Create virtual environment
python -m venv cira-ml-env

# Activate environment
cira-ml-env\Scripts\activate
```

**Windows PowerShell:**
```powershell
# Create virtual environment
python -m venv cira-ml-env

# Activate environment
cira-ml-env\Scripts\Activate.ps1
```

**Linux/macOS Terminal:**
```bash
# Create virtual environment
python3 -m venv cira-ml-env

# Activate environment
source cira-ml-env/bin/activate
```

#### 3. Install Dependencies

**All Platforms:**
```bash
# Install core dependencies
pip install -r requirements.txt

# Verify installation
python -c "import streamlit, sklearn, xgboost; print('✅ All dependencies installed successfully')"
```

#### 4. Launch CIRA-ML

**Windows (After activating virtual environment):**
```cmd
# Start the ML-enhanced platform
streamlit run app.py

# Optional: Launch with custom port
streamlit run app.py --server.port 8502
```

**Linux/macOS (After activating virtual environment):**
```bash
# Start the ML-enhanced platform
streamlit run app.py

# Optional: Launch with custom port
streamlit run app.py --server.port 8502
```

#### 5. Access the Platform
- **Default URL**: `http://localhost:8501`
- **Alternative Port**: `http://localhost:8502` (if specified)
- **Network Access**: `http://[your-ip]:8501` (for team access)

### Advanced Installation Options

#### Docker Deployment
```bash
# Build CIRA-ML container
docker build -t cira-ml:latest .

# Run with ML optimization
docker run -p 8501:8501 --memory=8g cira-ml:latest
```

#### Production Deployment
```bash
# Install production dependencies
pip install -r requirements-prod.txt

# Configure for production
export STREAMLIT_SERVER_ENABLE_CORS=false
export STREAMLIT_SERVER_ENABLE_XSRF_PROTECTION=false

# Launch with production settings
streamlit run app.py --server.enableCORS false --server.enableXsrfProtection false
```

## 🔬 ML-Enhanced Risk Calculation Methodology

### 🧠 Unified Risk Scoring Framework

#### **Traditional + ML Integration**
```
Base Risk = Asset Value × Vulnerability × Threat Likelihood × Impact
ML Enhancement = ML Confidence × Prediction Accuracy × Model Consensus
Unified Risk Score = (Base Risk × ML Enhancement) + Temporal Adjustment + Federated Intelligence
```

#### **Component Weighting in Unified Score**
- **🛡️ ML-Enhanced STRIDE Analysis**: 40% weight
- **🤝 Federated Intelligence Benchmarking**: 25% weight
- **📈 Temporal Risk Projections**: 20% weight
- **💡 Adaptive Learning Adjustments**: 15% weight

### 📊 ML-Enhanced Risk Levels

| Risk Level | Score Range | ML Confidence | Description |
|------------|-------------|---------------|-------------|
| 🟢 Very Low   | 0-19        | 95%+ | Minimal risk, AI-verified safe patterns |
| 🟡 Low        | 20-39       | 90%+ | Low risk, ML-confirmed standard security |
| 🟠 Medium     | 40-59       | 85%+ | Moderate risk, enhanced ML monitoring |
| 🔴 High       | 60-79       | 80%+ | High risk, ML-flagged immediate attention |
| ⚫ Critical   | 80-100      | 75%+ | Critical risk, ML emergency protocols |

### 🛡️ ML-Enhanced STRIDE Categories

#### **🤖 Dynamic Threat Modeling**
- **S**poofing: Identity attacks + ML anomaly detection (Influence Factor: 0.3)
- **T**ampering: System modification + ML integrity monitoring (Influence Factor: 0.2)
- **R**epudiation: Action denial + ML audit analysis (Influence Factor: 0.1)
- **I**nformation Disclosure: Data access + ML pattern recognition (Influence Factor: 0.4)
- **D**enial of Service: Availability attacks + ML traffic analysis (Influence Factor: 0.6)
- **E**levation of Privilege: Access escalation + ML behavioral analysis (Influence Factor: 0.25)

#### **🎯 ML Influence Calculation**
```python
ML_Influence = (ML_Risk_Score - 50) / 100 × Category_Sensitivity
Enhanced_Likelihood = Base_Likelihood × (1 + ML_Influence)
Enhanced_Risk = (Enhanced_Likelihood × Enhanced_Impact) / 10
```
